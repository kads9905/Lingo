P19 · Encoder–Decoder Translator, English to Hindi and Marathi

1. Goal

Translate text and image captions, and compare a seq2seq model with an LLM on quality, speed and fairness.

2. System

A React frontend on Vercel calls a FastAPI backend on Render, which holds the keys, applies the guardrails and calls Groq or Gemini. PyTorch with one MarianMT model measured 808 MB of RAM against Render's free 512 MB, so the PyTorch models run on a free Hugging Face Space, as the brief allows for heavy models.

4. Tasks

U1. Four registers (neutral, formal, casual, for children), each with zero-shot and few-shot prompts. Source text sits in delimiters and is treated as data.

U2. MarianMT and the LLM run side by side. Marathi uses opus-mt-en-inc, because opus-mt-en-mr invented content in testing.

U3. BLIP captions an upload, then both models translate the caption.

U4. Any translation can be spoken with gTTS.

U5. Gender bias is measured below and can be probed live in the Bias lab.

8. Guardrails

Input length and harmful-request filters, delimiting against prompt injection, Devanagari output validation, per-client rate limiting, a gender notice, and a BERT-family meaning check.

On 40 correct and 40 shuffled pairs, the meaning check at threshold 0.55 caught 100.0% of unrelated pairs and passed 100.0% of correct ones (AUC 1.0). That is an easy test. On MarianMT's 10 lowest-BLEU outputs it flagged only 1, so it stops unrelated text but misses translations that are wrong yet on topic, such as a literal idiom. Not every low-BLEU output is wrong, but this guardrail must not be treated as an accuracy check.

9. Limitations

Twenty sentences with one reference each is a small test, so small differences are not meaningful. The references were drafted with AI assistance and should be reviewed by a fluent speaker. The keyword filter is not full moderation, and the gender detector covers common verb forms only.
